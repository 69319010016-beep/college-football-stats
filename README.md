# college-football-stats
เว็บประชาสัมพันธ์การแข่งขันฟุตบอลและติดตามสถิตินักกีฬาในวิทยาลัย
## รายละเอียดโครงงาน

เว็บไซต์สำหรับประชาสัมพันธ์การแข่งขันฟุตบอลในวิทยาลัย แสดงตารางการแข่งขัน ผลการแข่งขัน และสถิติของนักกีฬา

## Team Charter

### สมาชิกทีม

- **ชื่อ:** ธีรภัทร ช่วงชาวนา
- **บทบาท:** Developer / Project Leader
- **สิ่งที่อยากเรียนรู้:** การพัฒนา Backend ด้วย Node.js การสร้าง REST API และการใช้ Git/GitHub

### หมายเหตุ

ปัจจุบันดำเนินโครงงานโดยสมาชิก 1 คน เนื่องจากสมาชิกเดิมลาออก
